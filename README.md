# HinexFeatures — клиентский мод сервера Hinex

Исходный код мода, который ставят игроки сервера **Hinex** (Minecraft 26.3: Fabric, NeoForge, Forge).
Код открыт, чтобы любой мог проверить, что делает мод. Без сервера Hinex почти все функции не работают.

Готовые сборки и настройки — в репозитории [Jaikop/hinex-features](https://github.com/Jaikop/hinex-features).

## Сеть и данные

Мод соединяется только с этими адресами:

| Куда | Зачем |
|---|---|
| `raw.githubusercontent.com`, `cdn.jsdelivr.net` (репозиторий `Jaikop/hinex-features`) | настройки мода, ресурспак, новые версии мода |
| `api.minecraftservices.com` (Mojang) | проверка лицензии игры — так же, как это делает сама игра; токен входа уходит только Mojang |
| сервер Hinex, на котором играешь | данные ниже |
| Discord на этом же компьютере | статус «играет на Hinex» |

**Что получает сервер Hinex** (код — `common/src/main/java/me/JAKOP/hinexFeatures/mod/dossier`):
ник и UUID, версия мода, характеристики ПК (процессор, видеокарта, объём памяти, модель материнской платы, ОС),
список модов и ресурспаков, настройки графики, разрешение экрана, язык и часовой пояс, лаунчер,
HWID — SHA-256 от серийных номеров железа (сами номера не отправляются). Другим серверам ничего не уходит:
данные отправляются только серверу, где стоит серверная часть HinexFeatures.

**Что мод меняет на компьютере:** обновляет сам себя (файл новой версии сверяется с SHA-256 из настроек
и при несовпадении не ставится) и отключает запрещённые моды из списка в настройках (например, Freecam): переименовывает
их файл в `.jar.disabled` — вернуть можно, просто переименовав обратно.


## Устройство

```
common/       — весь код мода (общий для загрузчиков)
fabric/       — запуск на Fabric
neoforge/     — запуск на NeoForge
forge/        — запуск на Forge (отдельная сборка)
build-logic/  — общие настройки сборки
```
